# SPEC — 仕様書とリバースエンジニアリング

実装した内容だけを書く。**未実装のものを書かない。**

現時点では `src/` が存在せず、実装済みの内容がないため、ここに仕様はまだありません。

## 仕様の出どころ

実装前の仕様は、リポジトリ直下の `requirements.md` が正です。同ファイルの 21〜26 章（ER 図・DFD・シーケンス図・クラス図・状態遷移図・ユースケース図）は**設計**であり、実装済みの内容ではありません。

## ここへ置くもの

実装が済んだ機能から順に、実装を読み取って次を書き起こします（リバースエンジニアリング）。図は Mermaid で書きます。

| 種類 | 置き場 |
|---|---|
| ER 図 | `SPEC/er/` |
| DFD | `SPEC/dfd/` |
| シーケンス図 | `SPEC/sequence/` |
| クラス図 | `SPEC/class/` |
| 状態遷移図 | `SPEC/state/` |
| ユースケース図 | `SPEC/usecase/` |
| API 仕様（タイトル・エンドポイント URL） | `SPEC/api/` |

README.md の API 一覧は、`SPEC/api/` の各ファイルへリンクします。
