# app-ui — 画面モック

`src/` へ再現するための画面モック（図案）。見た目の正本であって、仕様ではない。仕様は `requirements.md` が正で、食い違いを見つけたら `requirements.md` に従い、モックを直す。

## 出どころ

Claude Design のプロジェクト「browser-youtube-live-mvp モック」（デザインシステムは `veyra-gemini`）の内容を写したもの。

1. 最初の配置（コミット 29ad7fd）は、Claude Design の内容をそのまま写した（バイト数が元と一致）
2. その後、`requirements.md` を読み直して食い違いを直した。**同じ内容を Claude Design 側にも反映済み**（全ファイルのバイト数が一致）。元の版に戻す場合は 29ad7fd を使う

## 入れていないもの

| 項目 | 理由 |
|---|---|
| `support.js`（約 66 KB） | Claude Design が出力する実行時。`.dc.html` を描画するのに要る。再生成する場合は Claude Design 側から取得する |
| `tokens/fonts-local.css`（約 12.8 KB）・woff2 フォント | フォントの同梱ファイル。`styles.css` が読み込む。ライセンスの確認が済むまで入れない |
| `assets/`（`images/hero.webp` ほか） | 画像。出どころと利用許諾が未確認 |

## 見方

`.dc.html` は `support.js` が無いと描画されない（`<x-dc>`・`sc-if`・`sc-for` は Claude Design の記法）。このフォルダだけでは画面は開けないので、見るときは Claude Design のプロジェクトを開く。

## requirements.md に合わせて直した点

- ソースを、右パネル（ソース・健全性・記録）へ移した（17.4）。共有音声を加え、ソースの状態 5 種（未取得・要求中・取得済み・拒否・喪失）を表示する
- スタジオの状態を、10 種すべてにした（再接続中・停止中を追加。受付中・接続中・計測中・開始中を分けた）
- 状態表示を「ライブ」の文言にし、ヘッダにも配信中の状態を出した（17.4）。配信制御はプレビューの直下に固定した
- 開始に至らない場合は、強調する操作を理由に応じた対処（接続・再確認・再接続・再試行）へ置き換えた（17.1）
- 開始の拒否 14 種（9.2）、終了理由 13 種と原因・対処（16.5）、時間上限の予告・YouTube の警告・ソース喪失、配信に復帰（13.1）を追加した
- 開始中の段階表示を、要件の 6 段階の文言にした（16.4）。劣化は、目標ビットレートが下限のときに出る（12 章）。ソース喪失とは分けた
- 開始ダイアログの既定のタイトルを、「ライブ配信」に日時を付けたものにした（9.1）
- 非対応環境に、必須能力 5 件と任意の能力 2 件を示した（30.1）
- アカウントに、チャンネル名・接続不成立の 4 種・権限の取り消し案内・解除時の動作の説明を加えた（7.2・7.4・28.2）
- 利用規約・プライバシーポリシーの画面を追加し、全画面からリンクした（16.1）
- アクセシビリティ：操作部品の枠を 3:1 以上のコントラストにし、状態は文言と形の違う図形で示し、状態の領域を `aria-live` にし、動きの低減の設定に従う（17.2・17.6）

## 画面の文言

**モックの文言は仮置き**。`requirements.md` の表の語句（拒否理由・終了理由・案内の趣旨）を並べたもので、公開用の文章ではない。利用者が読む文章は、`CLAUDE.md` のとおり Gemini が書く。

利用規約・プライバシーポリシーのリンク先（YouTube 利用規約・Google プライバシーポリシー・Google アカウントの権限の管理）の URL は、**未確認**（GPT のファクトチェック未実施）。

## 再現するときの決まり

- `src/` にはこのモックの見た目を再現する。`.dc.html` の記法はそのまま持ち込まない（Next.js のコンポーネントとして書き直す）
- 色・余白・書体は `tokens/*.css` の変数を使い、値を直接書かない
- モックの切り替え（`MOCK STATE`）は、実装には持ち込まない
- モックの文言が `requirements.md` と食い違う場合は、`requirements.md` を使う
