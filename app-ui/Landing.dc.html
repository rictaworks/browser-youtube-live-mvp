01VALUE

Why a Tab

No Install

対応ブラウザでページを開けば、配信できます。

No Stream Key

配信枠・配信キー・紐づけは、システムが自動で用意します。配信キーを見ることも、貼ることもありません。

One Screen

ソースの準備・プレビュー・開始・健全性の確認・停止を、1 画面で行います。

Auto Close

タブを閉じた場合や回線が切れた場合も、配信が YouTube 上に残り続けません。

Before You Start

  • YouTube チャンネルを持ち、ライブ配信が有効になっていること。有効化には時間がかかる場合があります。
  • YouTube の利用条件（配信者の年齢要件を含む）を満たしていること。
  • 上り回線の実効スループットが 1,200 kbps 以上あること。
